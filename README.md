# FlowStudy (React)

Flexible task-based study planner with compulsory minimum durations, routine customization, and progress tracking.

Rewritten from Android (Kotlin / Jetpack Compose) to React + TypeScript + Tailwind CSS with full feature parity.

## Core Features
- **Task-Based Flexible Flow**: Study tasks feature compulsory minimum duration commitments. Reaching the minimum milestone triggers the **Flow State** (+bonus flow overtime), allowing open-ended or deliberate extension.
- **Prepopulated Competitive Student Routine**: High-yield syllabus (Physics Theory, Chemistry Mechanisms, CET Mock MCQs, Numerical Problem Sets, Flashcard Synthesis, Flexible Meals & Walks).
- **Preset Routine Templates**: Instant switching between *Balanced Flow*, *Deep Work Focus*, and *Fast Exam Sprint*.
- **Task Management**: Reorder via interactive index order steppers, duplicate, delete with confirmation, and custom duration adjustments with hours/minutes steppers.
- **Active Focus Session Chronograph**:
  - Full-screen immersion with active backdrops (AMOLED, Forest, Mountain, Sky, Countryside, Aurora Gradient, or Custom URL).
  - Picture-in-Picture / Floating window mini-mode for side-by-side study with YouTube lectures.
  - Lecture Mode: Discrete mini floating pill to eliminate visual countdown stress.
  - Interactive extensions (+5m, +15m) and distraction click-counter.
  - Incomplete exit protection: Warns and logs interrupted stints if minimum is abandoned early.
- **30-Second Auto-Start Transition Alarm**:
  - Ticking circular countdown with urgent pulse alert under 10 seconds.
  - Zero-asset Web Audio API harmonic sound synthesizers: *Zen Gong* (432Hz), *Temple Bell* (528Hz), *Cyber Pulse*, and *Digital Alarm* waking beeps.
  - Automatically advances to the next compulsory study block or lets you choose flexible break options.
- **Study Analytics & Progress**:
  - Today vs Weekly / All-Time analytics tabs.
  - Subject-wise breakdown bars and qualifying study streaks.
  - Full session history log with interruption indicators and flow overtime bonuses.
  - CSV export for spreadsheets.
- **Customization & Shield**:
  - Focus Screen element toggles (hide timers, minimal mode).
  - Focus Shield distraction blocker.
  - JSON backup export and restore.
